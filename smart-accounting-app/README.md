# تطبيق "الحساب الذكي" لسطح المكتب

هذا المشروع يوفر هيكلًا أوليًا (Scaffold) لتطبيق محاسبي ذكي باللغة العربية مبني باستخدام **Electron** و **React (Vite)** مع خدمات خلفية Express جاهزة لتغذية لوحة المعلومات بالبيانات.

## ما تم تنفيذه
- تشغيل واجهة React داخل بيئة Electron مع قناة `preload` للتبديل بين الوضعين الليلي والنهاري وتمرير عنوان الـAPI الآمن من خلال سياق معزول.
- لوحة معلومات عربية تعرض مؤشرات رئيسية، مخطط تدفقات نقدية، تنبيهات مدعومة بالذكاء الاصطناعي، نشاط حديث، ورؤى ذكية مع زر تحديث فوري ومؤشرات لحالة الاتصال.
- طبقة خدمات أمامية (`src/services`) تتصل فعليًا بخدمات Express الخلفية مع آلية تخزين مؤقت وسيناريو بديل عند انقطاع الاتصال.
- أنماط CSS مهيأة لدعم الاتجاه من اليمين لليسار وتناسق الألوان في الوضعين الفاتح والداكن.
- خادم Express يوفّر نهايات (Endpoints) جاهزة لكل قسم من أقسام لوحة التحكم (`/api/dashboard/*`).

## الخدمات الخلفية (Express API)

يحتوي مجلد المشروع الجذري على تطبيق Express يقوم بتقديم البيانات التالية:

| المسار | الوصف |
| --- | --- |
| `GET /api/dashboard/snapshot` | يجلب حزمة كاملة من بيانات اللوحة (المؤشرات، المخطط، التنبيهات، الأنشطة، والرؤى).
| `GET /api/dashboard/overview` | مؤشرات الأداء الرئيسية.
| `GET /api/dashboard/cashflow` | بيانات التدفق النقدي للأشهر الستة الأخيرة.
| `GET /api/dashboard/highlights` | مزايا المنصة المفعلة.
| `GET /api/dashboard/ai-alerts` | توصيات الذكاء الاصطناعي.
| `GET /api/dashboard/activities` | آخر الأنشطة المنجزة.
| `GET /api/dashboard/insights` | رؤى تحليلية معمقة.

> **ملاحظة:** يتم تفعيل ترويسة CORS تلقائيًا للسماح للتطبيق المكتبي أو لبيئة التطوير بالوصول إلى الـAPI محليًا.

## ما يزال ناقصًا لإطلاق منتج فعلي
1. **مصادر بيانات حقيقية**: يجب ربط الخدمات الأمامية بواجهات برمجية (APIs) حقيقية أو قاعدة بيانات بدلاً من بيانات وهمية ثابتة موجودة في [`src/services/dashboardService.js`](src/services/dashboardService.js).
2. **إدارة جلسات المستخدم والصلاحيات**: يلزم إضافة تسجيل دخول، صلاحيات، وربطها بخدمات الحسابات.
3. **التقارير المحاسبية**: إنشاء شاشات تفصيلية للتقارير (الأرباح والخسائر، الميزانية العمومية، الزكاة والضريبة...).
4. **التكاملات البنكية والضريبية**: بناء موصلات (Integrations) مع الأنظمة المحلية كما هو موضح في واجهات المستخدم الحالية.
5. **اختبارات تلقائية**: إضافة اختبارات وحدات وواجهات لضمان استقرار التطبيق.
6. **عمليات البناء والتعبئة (Packaging)**: إعداد أدوات مثل `electron-builder` أو `electron-forge` لتوليد ملفات تنفيذية لأنظمة التشغيل المختلفة.
7. **التدويل وإدارة النصوص**: نقل السلاسل النصية إلى ملفات ترجمة لدعم لغات متعددة وإدارة الصياغة من مكان مركزي.
8. **الأمان والتوقيع الرقمي**: تطبيق سياسات أمان في `preload` و`main` (مثل Content Security Policy) وتوقيع الحزم قبل الإطلاق.
9. **مسارات الدعم وإعدادات المستخدم**: تطوير صفحات لإدارة الحساب، إعدادات الفواتير، وإرسال البلاغات للدعم.

## كيفية التشغيل محليًا
> **ملاحظة:** قد يفشل تثبيت الحزم في البيئات المحجوبة عن الإنترنت. تأكد من توفر اتصال إلى سجل npm أو استخدم مرآة محلية.

### تشغيل الخادم الخلفي

```bash
# من جذر المستودع الحالي
npm install
npm start
```

سيعمل الخادم على المنفذ `3000` افتراضيًا.

### تشغيل الواجهة المكتبية (Electron + React)

```bash
cd smart-accounting-app
npm install
npm run dev
```

سيقوم Vite بتشغيل الواجهة على المنفذ `5173` بينما يقوم Electron بتحميلها معتمداً على خدمة الـAPI في `http://localhost:3000/api` (أو حسب قيمة المتغير `API_BASE_URL`).

## الخطوات التالية المقترحة
- تصميم مخطط قاعدة بيانات (مثل PostgreSQL) وربطه بخدمة Express أو NestJS لتوفير بيانات حقيقية.
- إضافة وحدة إدارة فواتير ومصروفات مع إمكانية التصدير إلى Excel/PDF.
- دمج نماذج تعلم آلي لتحليل التدفق النقدي والتنبؤ بالتكاليف.
